# 学习计划设计说明

目标学员：在埃塞俄比亚从事 IT / 通信 / 设备交付工作的中文母语成年人，每天可投入 30–45 分钟。8 周目标是用阿姆哈拉语独立应对工作沟通：给司机后勤安排行程、接打电话、在现场向一线班组布置任务并确认完成、用敬语接待客户与政府官员、报告问题并跟进到解决。生活场景（住宿、市场、餐馆、大数字）降为自选补充单元，时间充裕再学。

## 一、成人学习特性 → 设计决策

| 成人学习特性（Knowles 成人教育学 + 认知科学） | 计划中的落实 |
| --- | --- |
| 需要知道"为什么学" | 每周、每单元都有 `why` 字段说明真实收益（如"不回问候会被当作冷淡"、"约错埃塞时间是最常见的失误"） |
| 自我导向 | 每日时长、新词上限、开始日期可调；单元可跳着学；自选单元学不学由学员决定；AI 只给建议和依据，采纳与否由学员决定 |
| 经验为本 | 数字、时间、货币和已有概念对照（埃塞时间 = 国际时间 − 6；埃塞历比公历晚 7–8 年）；现场词汇（塔、光纤、发电机）挂在学员已有的行业经验上 |
| 问题中心、即学即用 | 按工作场景而非语法编排；每周一个必须在现实中完成的工作任务（mission）：安排行程、打电话、现场布置、敬语接待、报告问题 |
| 内在动机 | 连续天数、里程碑、AI 诊断中基于数据的具体肯定；退步只诊断原因不批评 |
| 时间碎片化 | 每天约 33 分钟 = 8 复习 + 15 新内容 + 10 小测/实战；单元 18–33 条，两天学完 |
| 遗忘曲线 | SM-2 间隔重复；忘了的卡 10 分钟后重现；小测结果回写 SRS；错得多的词在小测中优先出现 |
| 主动回忆优于重读 | 闪卡要求先在心里说出答案再翻面；小测为选择题提取练习；对话页可遮住转写 |
| 认知负荷 | 每日新卡上限（默认 15）；Fidel 33 个辅音分 5 批，每周约 6 个，并与当周词汇绑定；自选单元不计入周完成度 |
| 定期反思与调整 | 第 4、8 周为复习周，减少新词，做 AI 诊断；每周第 7 天复盘 |

## 二、每周节奏

| 天 | 内容 |
| --- | --- |
| 1–2 | 闪卡复习 + 单元 A（第 1 天通读并加入闪卡，第 2 天看对话和用法提示）+ 本周 Fidel 批次 |
| 3–4 | 闪卡复习 + 单元 B + 单元 A 小测 |
| 5 | 闪卡复习 + 对话跟读（三遍：看转写 → 遮转写 → 只看中文）+ 单元 B 小测 + 自选单元（如本周有，`optional: true`，不计入完成度） |
| 6 | 闪卡复习 + 工作实战任务（现实中完成后打钩）+ 自选单元（同上） |
| 7 | 闪卡复习 + 本周综合小测 + 复盘（复习周做 AI 诊断） |

## 四、AI 诊断与计划调整

上传给 DeepSeek 的数据（不含聊天记录）：当前周/天、连续天数、已学与落后单元、各单元小测成绩、SRS 总量/到期/熟练、最近 7 天复习正确率、最近 14 天每日时长、遗忘最多的 10 个词、已完成的实战任务、学员自述。计划大纲（`planOutline()`）会告诉 AI 学员目标是工作沟通（IT / 通信 / 设备交付：司机后勤、一线班组、办公室同事、客户与政府），并列出每周主单元与自选单元，AI 据此把建议对准工作场景。

**诊断输出**：整体水平与分数、总体判断、优势、薄弱点、风险、建议（含优先级）、计划改动建议、每日时长建议、未来 7 天重点、基于数据的鼓励。

**计划调整输出**：调整思路、每日分钟数、每日新词量、复习占比、按周改动（含依据）、学员诉求对应的补充内容（含示例表达）、本周实战任务、一周后的量化检查点。

调整原则写在提示词里：落后时延长周期或砍低优先级内容（优先砍自选单元）而不是堆量；正确率低于 70% 减新词加复习；学员的工作场景诉求优先排入最近两周；不推翻已完成部分。

学员点"采纳"后，每日目标和新词上限立即生效，按周改动显示在计划页对应周下方；可随时恢复默认。
