# 学习计划设计说明

目标学员：在埃塞俄比亚工作/生活的中文母语成年人，每天可投入 15–25 分钟，目标是 8 周内用阿姆哈拉语独立应对日常生活（问候、买东西、打车、点餐、约时间、求助）。

## 一、成人学习特性 → 设计决策

| 成人学习特性（Knowles 成人教育学 + 认知科学） | 计划中的落实 |
| --- | --- |
| 需要知道"为什么学" | 每周、每单元都有 `why` 字段说明真实收益（如"会说 ውድ ነው、ቀንስ 立刻能省钱"） |
| 自我导向 | 每日时长、新词上限、开始日期可调；单元可跳着学；AI 只给建议和依据，采纳与否由学员决定 |
| 经验为本 | 数字、时间、货币和已有概念对照（埃塞时间 = 国际时间 − 6；埃塞历比公历晚 7–8 年） |
| 问题中心、即学即用 | 按场景而非语法编排；每周一个必须在现实中完成的实战任务（mission） |
| 内在动机 | 连续天数、里程碑、AI 诊断中基于数据的具体肯定；退步只诊断原因不批评 |
| 时间碎片化 | 每天 20 分钟 = 5 复习 + 10 新内容 + 5 小测/实战；单元 18–26 条，两天学完 |
| 遗忘曲线 | SM-2 间隔重复；忘了的卡 10 分钟后重现；小测结果回写 SRS；错得多的词在小测中优先出现 |
| 主动回忆优于重读 | 闪卡要求先在心里说出答案再翻面；小测为选择题提取练习；对话页可遮住转写 |
| 认知负荷 | 每日新卡上限（默认 10）；Fidel 33 个辅音分 5 批，每周约 6 个，并与当周词汇绑定 |
| 定期反思与调整 | 第 4、8 周为复习周，减少新词，做 AI 诊断；每周第 7 天复盘 |

## 二、每周节奏

| 天 | 内容 |
| --- | --- |
| 1–2 | 闪卡复习 + 单元 A（第 1 天通读并加入闪卡，第 2 天看对话和用法提示）+ 本周 Fidel 批次 |
| 3–4 | 闪卡复习 + 单元 B + 单元 A 小测 |
| 5 | 闪卡复习 + 对话跟读（三遍：看转写 → 遮转写 → 只看中文）+ 单元 B 小测 |
| 6 | 闪卡复习 + 实战任务（现实中完成后打钩） |
| 7 | 闪卡复习 + 本周综合小测 + 复盘（复习周做 AI 诊断） |

| 周 | 主题 | 单元 | Fidel | 里程碑 |
| --- | --- | --- | --- | --- |
| 1 | 打招呼 + 数字 1–10 | u01 问候礼貌、u02 数字与"是/不是" | 第 1 批 ሰ ለ መ ነ በ አ | 问候一个来回 + 报电话号码 |

| 5 | 句子骨架 | u08 代词/有/疑问词、u09 形容词 | 第 4 批 ዘ ጀ ኘ ጠ ጨ ጸ | 现场造 10 个新句子 |

| 8 | 综合复习 + 实战周 | 不加新词 | 全表自测 | 复习正确率 ≥ 85%，5 个实战任务完成 |

## 四、AI 诊断与计划调整

上传给 DeepSeek 的数据（不含聊天记录）：当前周/天、连续天数、已学与落后单元、各单元小测成绩、SRS 总量/到期/熟练、最近 7 天复习正确率、最近 14 天每日时长、遗忘最多的 10 个词、已完成的实战任务、学员自述。

**诊断输出**：整体水平与分数、总体判断、优势、薄弱点、风险、建议（含优先级）、计划改动建议、每日时长建议、未来 7 天重点、基于数据的鼓励。

**计划调整输出**：调整思路、每日分钟数、每日新词量、复习占比、按周改动（含依据）、学员诉求对应的补充内容（含示例表达）、本周实战任务、一周后的量化检查点。

调整原则写在提示词里：落后时延长周期或砍低优先级内容而不是堆量；正确率低于 70% 减新词加复习；学员的场景诉求优先排入最近两周；不推翻已完成部分。

学员点"采纳"后，每日目标和新词上限立即生效，按周改动显示在计划页对应周下方；可随时恢复默认。
