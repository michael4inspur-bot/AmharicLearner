# 小程序内管理端 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 管理员在小程序内管理用户账号、查看系统与费用、发公告；用户自填昵称。

**Spec:** `docs/superpowers/specs/2026-09-11-admin-design.md`（实施者必须先读 spec；本计划只写任务边界、接口与测试要求）。

- 云函数 CommonJS，`node:test`，测试不依赖 wx-server-sdk；`db.js` 只做 `node --check` 与桩加载。
- 错误码只有 `BAD_REQUEST / NO_API_KEY / UPSTREAM / TIMEOUT`。
- 页面样式遵循 `miniprogram/app.wxss` 的方案 C 变量与 class，图标用 `<x-icon>`，禁止 emoji，不改 `app.wxss`。

### Task 1: 云函数——用户、状态、公告、管理动作、错误日志

**Files:** Create `cloudfunctions/api/admin.js`, `cloudfunctions/api/test/handler.admin.test.js`；Modify `cloudfunctions/api/handler.js`, `db.js`, `index.js`, `test/fakeDb.js`。

**Produces：**
- `db` 新方法（真实 + fakeDb）：`getUser(openid)`, `putUser(openid, patch)`（merge upsert，`doc(openid).set` 前先 get 合并）, `listUsers()`（全部，≤1000）, `deleteUserData(openid)`（删 `progress` 文档、分批删该 openid 的 `ai_logs`）, `getSetting(id)`, `putSetting(id, doc)`, `addErrorLog(entry)`, `listErrorLogs(limit)`, `pruneErrorLogs(keep)`, `countAiByDay(sinceIso)`（聚合：`match({type:_.in(['diagnosis','plan','chat']), date:_.gte(since)})` → `project({day: $.substr(['$date',0,10])})` → `group({_id:'$day', count: $.sum(1)})` → 返回 `[{date, count}]`）, `ttsCacheStats()`（`count()` + 聚合 sum chars）, `listTtsCache(limit)`（返回 `[{_id, fileID}]`）, `removeTtsCache(ids)`。
- `admin.js`：`handleAdmin(action, data, ctx)` 处理 `user.setProfile`、`user.me`、`announcement.get`、`admin.users`、`admin.setStatus`、`admin.deleteUser`、`admin.system`、`admin.clearTtsCache`、`admin.setAnnouncement`；导出 `handleAdmin`, `USER_STATUSES`。管理员判定用 `limits.isAdmin`。`admin.system` 的 `monthChars` 复用 `getLimits().ttsMonthlyChars` 与 `db.sumTtsCharsSince(monthStartIso(now))`，`aiToday` 用 `countAiByDay` 当天项，`aiDaily` 补齐 14 天（无数据为 0，按日期升序），`errors` 用 `listErrorLogs(20)`。
- `handler.js`：
  1. action 以 `user.`、`announcement.`、`admin.` 开头 → `handleAdmin`（`admin.usage` 现有实现保留在 handler 内，但先经过状态与鉴权逻辑不变）。
  2. 状态拦截：在分发 `ai.`/`tts.`/`stt.` 前 `const u = await db.getUser(openid)`；`u && u.status !== 'active'` → `fail('BAD_REQUEST','账号已被管理员暂停')`；`progress.get/put` 在 `status === 'blocked'` → `fail('BAD_REQUEST','账号已停用')`。
  3. `progress.put` 成功后 `db.putUser(openid, { lastActive: now, week, streak, stars, createdAt(仅首次) })`，其中 `week/streak/stars` 来自 `data.meta`（缺省 0）。
- `index.js`：catch 中 `await db.addErrorLog({date, openid, action, message: msg.slice(0,300)})` 与 `db.pruneErrorLogs(200)`，均 try/catch 静默。

**Tests（handler.admin.test.js，至少 14 个）：** setProfile 长度校验与写入；user.me 返回昵称与状态；progress.put 写摘要与 createdAt 仅首次；paused 用户 ai.chat 被拒、progress.put 可用；blocked 用户 progress.put 被拒；非管理员 admin.users 被拒；admin.users 合并当日用量并标 isSelf；setStatus 非法值、对自己被拒、正常修改；deleteUser 缺 confirm 被拒、成功后 progress/ai_logs 消失、users 变 blocked；admin.system 结构与 aiDaily 14 项；clearTtsCache 删除文件与文档；公告读写与 500 字上限；error_logs 裁剪到 200。

`cd cloudfunctions/api && npm test` 全部通过（之前 72）。桩加载 `index.js` 调 `main({action:'admin.users'})` 得 UPSTREAM db down。

### Task 3: 管理页面 `pages/admin/admin`

**Files:** Create `miniprogram/pages/admin/admin.{js,wxml,wxss,json}`；Modify `miniprogram/app.json`（注册页面）。

- 三个胶囊 Tab：用户 / 系统 / 公告；根容器 `class="page no-tab"`。
- 用户 Tab：`onShow` 调 `api.adminUsers()`；行：昵称或 `未命名 · 尾号 ${openid.slice(-4)}`、状态 `.tag`（active 薄荷"正常"、paused 桃色"已暂停"、blocked 灰"已停用"）、`lastActive` 前 10 位、`第 {{week}} 周 · 连续 {{streak}} 天 · {{stars}} 星`、`今日 AI {{today.ai}} · 语音 {{today.tts}} · 评分 {{today.stt}}`；`isSelf` 行右侧显示"我"标签且不可点；点击其他行 `wx.showActionSheet`（暂停 / 恢复 二选一按当前状态、删除）；删除先 `wx.showModal` 确认（内容含昵称与尾号），成功后刷新列表并 toast。
- 系统 Tab：`api.adminSystem()`；四个状态块（本月语音字符 + 进度条、今日 AI、语音缓存条数与字符 + "清理"按钮、错误条数）；14 天柱状条：`aiDaily` 映射为高度百分比（最大值为 100%），view 绘制，底部日期只显示每隔 3 天的 MM-DD；错误列表最多 20 条（时间前 16 位、action、message 前 80 字）。清理按钮 `wx.showModal` 确认后 `api.adminClearTtsCache()`，成功 toast 并刷新。
- 公告 Tab：`textarea.input`（maxlength 500）+ "发布"按钮 + 当前公告与更新时间；发布后 toast。
- 所有请求失败 `wx.showModal({title:'操作失败', content: err.message})`。
- 验证：`node --check`；WXML 配对；无 emoji；`app.json` 含 `pages/admin/admin`；假 wx 加载页面并调 `onShow()` 不抛错。
