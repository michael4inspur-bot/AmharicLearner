# 语音子系统 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为小程序加入 Azure 阿姆哈拉语朗读、听力题、跟读与发音评分。

**Architecture:** 云函数 `api` 新增 `tts.get / tts.batch / stt.score`，纯逻辑在 `speech.js`，Azure 与云存储通过注入的适配器访问；小程序 `utils/audio.js` 统一播放与本地缓存，各页面只调用它。

**Spec:** `docs/superpowers/specs/2026-09-11-speech-design.md`（实施者必须先读 spec，本计划只写任务边界、接口和测试要求）。

## Global Constraints

- 见 spec 第 3 节所有接口与常量；错误码只有 `BAD_REQUEST / NO_API_KEY / UPSTREAM / TIMEOUT`。
- 云函数目录 CommonJS；测试用 `node:test`，不依赖 wx-server-sdk（`azure.js`、`storage.js`、`db.js` 只做 `node --check`）。

- `test/fakeAzure.js`：`createFakeAzure({synth?: (text,voice,rate)=>Buffer|throws, recog?: (buf)=>{status,text}|throws})`，记录 `synthCalls`、`recogCalls`。
- `test/fakeStorage.js`：`createFakeStorage()`，内存 map，`upload` 返回 `cloud://fake/${cloudPath}`，`tempUrls` 返回 `https://fake/${fileID}`，`download` 返回上传过的 buffer（不存在抛错），`remove` 删除；暴露 `_files`。

### Task 3: `speech.js` 动作 + db 扩展 + handler 委托

**Files:** Create `cloudfunctions/api/speech.js`, `cloudfunctions/api/test/speech.test.js`；Modify `cloudfunctions/api/handler.js`, `cloudfunctions/api/db.js`, `cloudfunctions/api/test/fakeDb.js`, `cloudfunctions/api/test/handler.ai.test.js`, `cloudfunctions/api/index.js`

**Consumes:** Task 1 `scoring.js`，Task 2 适配器与假实现。

**Produces:**
- `speech.handleSpeech(action, data, ctx)`，ctx = `{openid, db, azure, storage, now}`；导出 `TTS_DAILY_LIMIT = 300`, `STT_DAILY_LIMIT = 100`, `VOICES = {female:'am-ET-MekdesNeural', male:'am-ET-AmehaNeural'}`, `ttsKey(voice, rate, text)`（sha1 hex，用 `node:crypto`）。
- `db.countAiSince(openid, sinceIso, types)`：`types` 为数组时只统计这些类型（真实实现用 `type: _.in(types)`）；`handler.js` 的 AI 上限改为传 `['diagnosis','plan','chat']`；`ai.history` 不变。
- `db.getTtsCache(key) => Promise<doc|null>`，`db.putTtsCache(doc)`（`_id` = key）。fakeDb 同步实现。
- `handler.js`：action 以 `tts.` 或 `stt.` 开头时 `return handleSpeech(action, data, ctx)`；`index.js` 注入 `azure: require('./azure.js')`、`storage: require('./storage.js')`。
- `tts.get`：校验 voice/rate/text（≤300，非空）；缓存命中 → `tempUrls`；未命中 → 上限检查（types `['tts']`）→ `azure.synthesize` → `storage.upload('tts/<key>.mp3')` → `putTtsCache` → `addAiLog({type:'tts', request: text.slice(0,100), result:{chars: text.length, key}})` → url。返回 `{url, key}`。
- `tts.batch`：≤40 条否则 BAD_REQUEST；对每条执行与 `tts.get` 相同逻辑，缺失项并发最多 5；单条失败不影响其他（该 id 省略）；返回 `{urls}`。
- `stt.score`：校验 fileID、target；上限（types `['stt']`）；`storage.download` → `azure.recognize` → `storage.remove([fileID])`（无论识别成败都删）→ status 非 `Success` 时 `{transcript:'', score:0, words: wordMatches(target,'')}`，否则用 `scoring` 计算；写 `addAiLog({type:'stt', request: target, result:{transcript, score}})`。
- Azure 错误映射同 AI（`err.code` 三种 → fail）。

**Tests（speech.test.js，至少 8 个）：** 首次 tts.get 调 azure 一次、上传一次、缓存一条、日志一条；第二次同 key 不调 azure；voice 非法 BAD_REQUEST；文本 301 字符 BAD_REQUEST；azure 抛 NO_API_KEY → code NO_API_KEY；tts.batch 三条其中一条已缓存 → azure 调两次、urls 三个键；stt.score 成功路径（文件被删除、score 100、日志 stt）；stt NoMatch → score 0；stt 第 101 次 BAD_REQUEST。`handler.ai.test.js` 新增：写入 20 条 tts 日志后 ai.chat 仍成功。

`npm test` 最终全部通过。

### Task 4: 小程序 `utils/audio.js` + api 扩展 + 设置

**Files:** Create `miniprogram/utils/audio.js`；Modify `miniprogram/utils/api.js`（追加 3 个方法）、`miniprogram/pages/profile/profile.js`、`profile.wxml`

**Produces（audio.js）：** `getSettings()`, `setSettings(partial)`, `speak(text, opts?) => Promise<void>`, `prefetch(items) => void`, `stop()`, `cacheKey(text, voice, rate)`。实现要点：
- 本地映射存 storage `audio_cache_v1`：`{[key]: filePath}`；目录 `${wx.env.USER_DATA_PATH}/tts`，首次用 `wx.getFileSystemManager().mkdirSync(dir, true)`（已存在的异常忽略）。
- 播放：`wx.createInnerAudioContext()` 单例，`src` 设本地路径或 url，`play()`；`onError` 时 toast "语音暂时不可用"。
- `speak`：命中映射且文件存在（`fs.accessSync` try/catch）→ 播放；否则 `api.ttsGet` → 立即用 url 播放，同时 `wx.downloadFile({url, filePath})` 成功后写映射。
- `prefetch`：过滤已缓存，`api.ttsBatch`（分批 ≤40），返回后逐个下载，同时最多 3 个，失败静默。
- 所有 `wx.*` 调用在模拟环境里可能是空函数，代码要容错（可选链或 try/catch）。

**api.js 追加：** `ttsGet: (text, voice, rate) => call('tts.get', {text, voice, rate})`，`ttsBatch: (items, voice, rate) => call('tts.batch', {items, voice, rate})`，`sttScore: (fileID, target) => call('stt.score', {fileID, target})`。

**profile：** 「学习设置」卡片增加"标准音"（女声 / 男声）和"语速"（正常 / 慢速）两组 radio，读写 `audio.getSettings/setSettings`。

**验证：** `node --check` 全部改动文件；`grep -n "ttsGet\|ttsBatch\|sttScore" miniprogram/utils/api.js` 三行。
